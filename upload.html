ഹോമിലേക്ക്

അപ്‌ലോഡ്

കുറിപ്പുകളും ഗെയിംസും ഇവിടെ നിന്ന് നേരിട്ട് വെബ്സൈറ്റിലേക്ക് ചേർക്കാം.

⚠️ ഇത് നിങ്ങൾക്ക് മാത്രമുള്ള പേജ് ആണ്. ഈ പേജിന്റെ ലിങ്ക് മറ്റാരുമായും പങ്കുവെക്കരുത് — ഇവിടെ ഉപയോഗിക്കുന്ന GitHub token നിങ്ങളുടെ repo-യിൽ എഴുതാൻ അധികാരമുള്ളതാണ്. Token ഈ പേജിൽ ഒരിടത്തും സേവ് ചെയ്യുന്നില്ല, ഓരോ തവണയും ടൈപ്പ് ചെയ്യേണ്ടി വരും. താഴെ "Token എങ്ങനെ ഉണ്ടാക്കാം" എന്നത് ഞെക്കി ആദ്യമായി ഒരു token ഉണ്ടാക്കൂ.
Token എങ്ങനെ ഉണ്ടാക്കാം? (ഒരു തവണ മാത്രം)
  1. github.com/settings/tokens തുറക്കുക (GitHub-ൽ ലോഗിൻ ചെയ്തിരിക്കണം)
  2. "Generate new token" → "Fine-grained token" തിരഞ്ഞെടുക്കുക
  3. Repository access → "Only select repositories" → നിങ്ങളുടെ repo (-) തിരഞ്ഞെടുക്കുക
  4. Permissions → "Contents" → "Read and write" ആക്കുക
  5. "Generate token" ഞെക്കുക, കോപ്പി ചെയ്യുക
  6. ഈ token ഒരിടത്തും ഷെയർ ചെയ്യരുത് — ഇത് നിങ്ങളുടെ repo-യിൽ എഴുതാൻ ഉള്ള താക്കോൽ ആണ്
  7. ഓരോ തവണ അപ്‌ലോഡ് ചെയ്യുമ്പോഴും ഇത് മുകളിലെ ബോക്സിൽ പേസ്റ്റ് ചെയ്യുക
